# Dashboard (WBS W9)

React + TypeScript. Initialize with:

```bash
npm create vite@latest . -- --template react-ts
```

Screens: 2D floor plan, A2A log, policy decision results, scenario panel (P0), developer panel (P1).
Includes a simple 2D floor plan of spaces and device states.
Connects to Gateway and Event Collector over WebSocket (`contracts/gateway`).
